# 智商测试对象与思考强度整合

日期：2026-11-21（Asia/Shanghai）。版本：插件 0.30.3、UI 13.7.3、内嵌 Go/Sobek 2.2.1。官方 CPA 8.0.76 源码不变，保留已有质量运维及账号管理逻辑。

## 用户可见变化

- 智商测试只有一个“测试对象”选择器，按 OAuth 账户、AI 提供商单条路由分组。供应商名称与路由索引直接显示，不再先切换类型、再选择供应商。
- 思考强度像质量运维一样直接点选。手动测试默认仍不附加思考参数，不自动改为 high。
- 每次手动测试仍绑定单个账户或单条供应商路由。整组授权、规则范围和自动处置继续属于质量运维，不因界面整合获得额外执行权限。
- 目录刷新保留模型与请求档位。原供应商、路由索引或已知支持档位失效时要求重新选择，不悄悄换对象或强度。历史重跑保留原绑定与提交回执保护。

## 修复原因与能力边界

旧页面依赖供应商通道目录，以公开模型 ID 直接匹配能力；自定义供应商、前缀和别名可能没有对应记录，预算字段也未保留，导致控件只能使用默认值。

后端现在优先投影已核实路由自己的显式配置，按精确别名、前缀和上游模型匹配可验证的静态目录。不同供应商即使使用相同别名，也保留各自配置。OpenAI 兼容配置未声明 thinking 的非图像模型沿用官方 low / medium / high 默认。自定义通道的聚合目录不能证明某条路由的能力，因此不借用其他条目的元数据。

| 能力信息 | 页面行为 |
| --- | --- |
| 已声明档位 | 显示该模型已知档位，包括支持时的关闭思考、minimal、auto |
| 预算型能力，没有离散档位 | 提供请求强度，由 CPA 转换并限制到模型预算 |
| 明确存在但没有档位或预算限制的 thinking 对象 | 显示标准请求档位并说明实际效果取决于 CPA 和上游 |
| 供应商能力未知 | 提供 low / medium / high / xhigh / max 请求档位；保留已有特殊请求，并明确能力未核实 |
| 普通账户能力未知，或精确目录明确无思考支持 | 只显示默认 |
| 非空但无法识别的档位列表 | 不将其误判为无限制，只显示默认 |

运行记录中的强度是请求值。官方 CPA 的模型转换、预算约束及最终 payload 配置可能调整、移除或覆盖参数，页面不声称已验证真实上游效果。停用路由定向探测的协议限制保持不变。
