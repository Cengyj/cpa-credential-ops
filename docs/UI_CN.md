# 页面使用与前端验证

UI 13.8.0 的「账号管理」「智商测试」「质量运维」共用浏览器的 CPA 访问身份。后台管理授权从插件数据卷恢复。各工作区独立读取数据，账号设置和历史使用对话框。页面连接、后台配置、退出和回执处理见[后台连接与浏览器验收](BACKGROUND_CONNECTION_CN.md)。

> 当前智商测试界面见 [0.30.4 下拉框恢复记录](REASONING_SELECT_0_30_4_CN.md)，供应商能力修复见 [0.30.3](MANUAL_PROVIDER_REASONING_0_30_3_CN.md)。文中带旧版本号的段落保留为历史记录，不代表当前宿主的可用操作。

> 历史版本 0.11.2 / UI 8.9.2 的账号显示、两行操作与行内日志见[账号显示与日志](OPENAI_ACCOUNT_REFERENCE_CN.md)。

下文三个子页是早期 OpenAI 工作区的设计。页面使用原生 HTML、CSS 和 JavaScript ES Modules，通过 `plugin/ui/embed.go` 嵌入动态库。修改页面后必须重建共享库，单独修改静态源码不会更新 CPA 已加载的插件。

## 三个独立入口

顶部导航为“智商测试”“质量运维”和“OpenAI 登录”。智商测试提供手动题目测试，质量运维提供规则检测与凭证暂停管理，OpenAI 登录提供账号导入、2FA 登录、授权候选、登录任务和明文账号资料管理。手动结果不会进入自动暂停判定，不输出通用 IQ 分数，也不提供探针或 ModelTrace。

智商测试的桌面工作区共用一个外框。左栏通过同一个“测试对象”下拉框选择 OAuth 账户或 AI 提供商单条路由，按类别分组；供应商名称与路由索引直接列在选项中。选择对象后，再从其已注册目录选择模型，思考强度保留原有下拉框，与回答数量并排。默认不附加思考参数，手动测试每次只绑定一个账户或一条路由，不包含整组执行。质量运维的规则范围只作用于各自的规则。右栏显示回答或测试记录，新建的供应商测试记录保存当时的供应商名称与路由索引。长题面和回答可独立滚动。点击“展开阅读”可以单独查看回答，窄屏则可在测试设置、本次回答和测试记录之间切换。

质量运维的「新建规则」和「编辑」共用一个弹窗，保存栏固定在底部。先勾选「OAuth 账户」「AI 提供商」中的一项或两项，再选「全部」「仅已启用」或「指定对象」。新规则默认检测已启用的 OAuth 账户，答错仅记录，定时关闭。指定对象下拉框将账户、提供商配置组、单条路由分开列出。勾选 AI 提供商后，思考强度可选「模型默认」。这会省略显式思考参数，可用于依赖 CPA 原生参数转换的停用路由。支持整组启停的配置组有单独的授权复选框，旁边列出受影响的路由索引。候选数量、恢复复检和未执行原因来自后端范围预览，执行时会重新匹配。目录待核实时仍可保存动态范围。升级后的旧规则沿用原范围，编辑者可显式勾选「采用当前规则的检测与处置范围」。[规则范围与处置说明](QUALITY_SCOPE_CN.md)

早期 UI 4.7–4.8 的桌面布局以 1280×720 的 CPA 窗口为主要目标，让配置、开始按钮和回答开头同屏。左侧顶行是凭证选择与题目选择（凭证在左），下方为题目编辑框；右侧集中放置模型、思考强度与回答数量，开始按钮位于选项下方，并与左侧题目编辑框底部对齐。题目版本及编辑提示独立排在下一行，不影响对齐。“重置题目”按钮已移除。正常凭证状态与模型数量贴近字段标签，阻止操作或能力未知时保留必要提示。长题面在编辑框内滚动，选项不设嵌套滚动区。窄屏先显示凭证、题目和编辑框，再显示模型设置与开始按钮；手机使用全宽主按钮。矮窗口及放大后允许页面滚动，不裁切表单或缩小关键文字。UI 4.7.1 调整布局；4.7.2 移除重置按钮、“选择凭证和模型后开始”及未连接时的“请先连接管理接口”提示。连接入口继续负责连接说明，开始按钮仍遵守鉴权和凭证限制。4.7.3 移除选模型前的思考强度提示和开始按钮上方横线。4.8.0 根据截图进一步调整：选项组最小间距为12px，开始按钮与编辑框底部对齐；下方回答与记录按内容收紧高度，只有“展开阅读”占满剩余空间。工具栏位于内容滚动区之外，空记录不再产生多余滚动或显示无效分页，普通回答文字宽度限制为80ch。4.8.1 将连接按钮移到顶部页签右侧，连接说明移入原有弹窗，不再占用单独提示行；桌面编辑框基础高度调整为128px，随右侧实际内容增高，消除空状态按钮上方的大段空隙并保留底部对齐。手机连接按钮保持44px触摸高度。

## 连接 CPA

CPA 中的插件入口为 `/management.html#/plugin-pages/model-quality/0`，也可以直接打开 `/v0/resource/plugins/model-quality/index.html`。公共资源只提供静态页面；凭证、题目、任务、规则、结果和动作通过同源 `/v8/management/plugins/model-quality/` 接口读取或操作。

在“管理连接”输入 CPA 管理密钥。请求使用 `Authorization: Bearer`，沿用宿主的 management 权限与远程访问策略。UI 8.3.1 起，成功连接后将密钥明文保存到当前源的 `localStorage`，键名为 `model-quality:management-key:/v8/management/plugins/model-quality`；刷新、重新打开和浏览器后退恢复页面时自动连接，不必重新输入。密钥不进入 URL、HTML 或 JSON 导出。CPA 管理中心与插件的连接分别建立，插件不读取父页面的认证存储，也不通过 URL 向 iframe 注入密钥。

点击“断开”或管理鉴权返回 401 时清除已保存的密钥；临时网络故障或服务错误不会清除已保存值。浏览器阻止本地存储时提示保存不可用，本次连接仍可在当前页面使用，刷新后需要重新输入。账号密码、2FA 和 OAuth 回调不写入浏览器存储。

打开页面、连接、刷新、切换题目、编辑题面和保存规则不会调用模型。只有显式开始测试、同配置再测试、立即执行规则或已启用的后台规则调度会提交模型调用。

内嵌页面沿用宿主侧栏与浮动工具，插件通过任务导航标明当前任务，并保留自己的连接状态。未连接时只有一个主要连接入口。正常同源 CPA 页面通过公开标题识别后，只读跟随父页根元素的 `data-theme`：无属性为浅色，`white` 为纯白，`dark` 为深色。监听属性变化，跟随时隐藏并禁用插件主题选择。宿主 auto 在系统浅色时实际应用纯白，因此不能把纯白并入浅色。独立打开、跨源、不可识别父页或主题适配异常时，安全回退到插件自己的浅色、纯白、深色选项。主题不写存储，不读取父页密钥或认证 store，也不代表管理接口已连接。

浮动工具避让基于固定宿主参考的顶部工具带，使用垂直留白；已移除原先 194px 右侧预留。内容边距由 iframe 内部承担，侧栏宽度不再次叠加。实际 iframe 宽度触发响应式布局，宿主展开、折叠侧栏及窄窗口需单独验收。

主动断连和 401 会清除密钥及页面中的管理数据，旧请求响应不能重填新会话。凭证数据未确认时禁止开始测试。轮询失败保留当前结果并重新读取进度，不重新发送模型请求；页面内刷新数据不会覆盖尚未提交的自定义题面，浏览器整页刷新会丢失未保存草稿。

## 题目测试

1. 在“测试对象”中选择 OAuth 账户或 AI 提供商单条路由。账户显示邮箱或条目标识，供应商显示名称与路由索引，不展示密钥。固定对象执行，不会自动换号；目录刷新后原供应商或索引不符时保留待核实选择，不自动改绑。
2. 从“测试模型”下拉直接选择一个模型。选择凭证后加载其宿主注册目录，并选择可用项；换凭证时保留仍可用的模型，否则切换到新目录首项。没有可用模型时禁用选择与开始操作，并提示在 CPA 检查配置后刷新。
3. 从原有思考强度下拉框选择档位，并选择 1–8 份回答。“默认”不显式提交思考参数。已知能力按当前路由与模型配置显示；预算型模型由 CPA 将档位转换并约束到支持预算。未知供应商能力可发送标准请求档位，界面明确实际支持取决于 CPA 转换和上游；普通账户能力未知或明确无思考支持时只显示默认。关闭思考、最低和自动按能力或既有请求保留。记录中的强度表示请求值，不保证是上游实际生效值。每份回答使用独立会话，同一任务逐份执行，不等于并行请求数。
4. 选择“糖果逻辑测试”“鹈鹕骑自行车（HTML）”或“自定义题目”，直接查看或编辑题面。糖果题使用版本化原题；HTML 题要求返回独立页面，以内联 SVG 绘制循环动画。内置题一经修改即标记“已修改”并按自定义题提交，不再沿用原题答案；“重置题目”可恢复当前内置题原文。同一次测试的每份回答使用相同的冻结题面。
5. 点击“开始测试”后，播放图标立即切换成加载环，按钮保留原文字和尺寸。旁边显示当前阶段，例如“提交中”“排队中”或“测试中”。此时重复点击或按 Enter 不会生成第二个任务。系统开启“减少动态效果”时，加载环静止。新手动任务不提交温度与输出上限覆盖值。服务端按 `min(2048, max_output_tokens)` 冻结每份回答的输出 token 预算。响应大小及每日预算仍生效，已保存的显式参数和同配置重跑仍采用原有校验。

原生流式测试分别计算回答正文和协议传输量。生成 HTML 时，每个小片段携带的模型标识和事件字段计入传输量。若接收达到上限，结果保留已经收到的正文，页面会标出中止原因。历史记录里的 HTML 片段也可查看，重新执行才会生成一份新的回答。

刷新目录时，仍然有效的模型和思考档保持不变。如果所选模型已从目录移除，或原思考档不再受支持，页面保留带“已不可用”说明的禁用旧选项并阻止提交，要求显式重选；不会在刷新时悄悄改变测试条件。主动切换凭证或模型后，新的目录和能力重新决定可用选项。

手动页使用 `judge.mode=manual`。读取回答时，后端可以按本轮冻结的标准答案核对适用的内置逻辑题。这个核对结果用于界面展示，手动测试不会因此触发凭证处理。

质量暂停、人工禁用和其他原生不可用条件都会阻止新测试。已经质量暂停的凭证不能用于任何复测，也不能用作质量规则的对照或判题凭证；服务端执行同样的限制。

## 看回答与测试记录

“本次回答”用本轮题目作为标题，模型和测试时间列在标题下方。测试进行时显示进度和“停止测试”；完成后收起进度条。桌面可点击“展开阅读”暂时收起配置，再点“返回配置”回到原草稿。

单份回答直接展示正文，短答放大显示。多份回答按序号在宽屏并排、窄屏纵向排列。绿色圆勾和朱红色叉号分别标记正确与错误，文字同时给出判定。内置逻辑题或随机题的短答经系统明确核对为错误、没有人工评审、且本轮保存了简短整数标准答案时，标准答案紧跟在回答原文旁边。执行失败、无正文和等待结果各有独立提示。

每份回答的总耗时、首字时间及 token 用量在正文下方，缺失值显示为“未知”。“复制原文”只复制模型输出。长文可展开阅读，HTML / SVG 可打开隔离的“作品预览”。“执行详情”按回答显示执行状态、判定依据、耗时与用量、模型路径及可展开的诊断信息。

标题旁的“测试详情”保存本次执行的冻结题面、凭证、模型及参数。回答区底部可以下载脱敏 JSON；“同配置再测试”在凭证可用时会提交一次新的调用。历史多模型记录可按当时的配置切换比较模型、筛选样本和查看人工评审。

“测试记录”按时间从新到旧分页。宽屏按列显示时间、题目和答题结果，凭证与模型在题目下方同一行。窄屏使用连续列表，以细线分隔记录，时间在右上角。有回答摘录时，摘录在上，判定在下。所有预期回答均已判定时，列表用图标和“答对数 / 回答总数”显示结果。绿色圆勾表示全对，朱红色感叹圈表示有回答答错。尚未判完、执行失败或发生历史裁剪时，列表逐项显示已有结果。有文字回答时会摘录首份有内容的回答，最多 96 个字符。HTML 和 SVG 作品显示类型，打开记录后可以预览。点击题目或记录可阅读完整原文和当时的测试条件，再点“返回测试记录”回到原页。旧版多模型、判题和对照记录也可按当时的条件审阅。[参考布局：sub2api 质量运维记录](https://github.com/ranxi2001/sub2api/blob/8678e88f4dfb6bfb718993db8a2a15b4a6af8282/frontend/src/views/admin/AccountQualityView.vue#L54-L71)

## 质量运维

“需要关注”展示暂停归属、关联规则、动作版本及待处理情况。凭证状态分别列出人工禁用、质量暂停、有效可用性与原因。质量暂停影响整个凭证所有模型的新业务执行；部分模型的证据不等于已经验证凭证所有可用模型。列表缺项不能作为暂停解除或凭证删除的证据。

“检测规则”按目标与题目、判定条件、检测调度、凭证处置、调用预算与保留分组，保留多模型、题目、样本、判题、固定间隔或五段 Cron、时区、预算、失败门槛和保留期。桌面长表单正文局部滚动，顶部关闭与底部保存操作保留在滚动区域之外。默认只观察；定时检测和自动暂停需要全局与规则分别许可，保存不会立即执行。同一凭证只允许一条自动暂停规则。

默认要求所有选定模型在连续三个完整有效轮次中均明确失败，才允许凭证级暂停。缺样本、unknown、混合结果、基础设施错误、条件或身份变化不构成新的暂停证据。质量通过率以可判定样本为分母，同时展示覆盖率；未知 usage 不当作零成本。

“暂停检测规则”只停止后续检测，不释放凭证暂停。凭证一旦质量暂停，所有依赖该凭证的检测规则和任务都停止，包括作为对照与判题的用途；不提供暂停中复测、自动恢复或复测周期。

“审计记录”保留规则检测、动作意图、暂停、人工解除及冲突记录。底层质量规则的判题配置、旧题目 ID 和持久化状态保持兼容；本轮简化针对手动题目测试流程。

## 人工解除

管理员从暂停归属打开解除预览，先核对凭证、owner、规则、动作版本、凭证身份和剩余限制，再点击“确认解除，保持检测停止”。只释放身份与归属匹配的本次暂停，不解除人工禁用、原生冷却或其他 owner 限制。

解除后相关规则仍停止，旧失败计数清零；必须单独恢复规则才会再次检测。版本或归属冲突需要重新读取当前状态并预览。网络或服务错误造成结果不确定时，使用“刷新并核对状态”，不能把失败响应直接当作宿主没有执行。

宿主持久保存质量暂停，重启、插件停用或卸载不会静默放行。插件不可用时使用宿主管理鉴权保护的查看和人工释放入口；回滚旧宿主前按安装文档处理暂停状态，不能删除数据库。

## HTML / SVG 安全预览

在「智商测试」完成一份包含 HTML 或 SVG 的回答后，可以直接在这份回答中看作品。其他回答仍在生成时，已完成的作品也可以阅读。打开测试记录可以查看以前保存的作品，源码和复制操作保留原始模型输出。接收中断的回答保留部分内容及中断原因。

作品显示在隔离的 iframe 内。长页面支持滚动，也可以放大查看；窄屏上的响应式 SVG 按作品自身的 viewBox 显示。本地 SVG 图形可以通过片段 ID 复用，如前后轮引用同一个定义。CSS 和 SVG 动画可播放。预览维持空 sandbox、内容安全策略与资源过滤，作品脚本不会执行，也不能访问管理页面或加载外部素材。原文始终按文本呈现。浏览器用 JavaScript 字符串长度限制预览输入，超过 1,048,576 个 UTF-16 码元时仍可阅读或复制原文。服务端接收回答的字节额度单独生效。

原版 sub2api 的即时结果、历史预览及实现位置见 [题目测试源码对照](SUB2API_QUESTION_TEST_CN.md)。

## 来源与版本

UI 借鉴 sub2api 题目测试的目录选择、题面编辑和逐份阅读流程，以 CPA 插件管理页与共享 UI 组件作为视觉基准。模型控件、题目执行及预览差异的源码依据见 [sub2api 界面研究](SUB2API_UI_RESEARCH_CN.md)。参考包括主题角色、系统字体、18px 卡片标题、8px 控件圆角、12px 卡片与弹窗圆角、下划线 ProviderTabs、44×24px 开关轨道、统一表格密度，以及 Modal/Sheet 的头部、滚动正文与底部动作骨架。为满足首屏操作要求，当前任务由导航直接标识，重复的可见页面标题移除；普通卡片采用 16px 内边距，正文与手机控件字号不因此缩小。实现仍为原生 HTML/CSS/ES Modules，不引入 React，也不复制宿主业务菜单。CPA 固定管理前端参考提交为 `d0126752201a35ff999bd2a1d4741215542258a8`，只读 CPA 8.0.67 源码基线保持不变。

UI 4.9.0 统一美化全部插件界面。浅色使用暖底色、明亮内容区与白色输入框，纯白使用轻微灰阶区分输入区域，深色保持独立表面层级。主按钮采用更明确的中性色；工作卡片只保留细边框，弹窗使用阴影。导航图标、选中态、数量标签及状态标签统一，题目与设置之间以留白区分。普通回答增加内部留白，历史记录增加可点击的方向提示。需要关注、规则与审计区域按内容收紧高度，规则编辑与预算页统一分组节奏；人工解除提示用琥珀色明确强调相关规则继续停止。手机弹窗保留20px底部留白。为满足普通小字的对比目标，行动色与部分边界、次级文字比宿主原值更深；手机字段文字至少 16px、主要触摸目标至少 44px。这些是有目的的可读性适配，不是无障碍认证声明。固定来源与许可证保留在 `plugin/NOTICE.md`。

糖果题来源、完整题面版本及 LGPL-3.0 许可记录在 `plugin/NOTICE.md` 和 [源码参考说明](SOURCE_AUDIT_CN.md)。鹈鹕 HTML 题面独立编写。旧 `logic-boxes`、`random-linear`、`visual-pelican` 的版本与内容保留，用于既有规则和历史。
