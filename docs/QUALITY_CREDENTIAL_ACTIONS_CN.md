# 质量运维的普通凭证处置

适用源码：插件 **0.30.0**、UI **13.7.0**，内嵌 Go/Sobek 运行时 **2.2.1**。普通停用使用 CPA 原有管理能力，与历史独立质量暂停分开。最新产品要求见 [质量运维逻辑](QUALITY_OPERATIONS_LOGIC_CN.md)，实际构建、集成与本地部署结果见 [本轮交付记录](QUALITY_OPERATIONS_0_30_0_CN.md)。

## 答错、错误与默认值

“答错后的处理”默认仅检测；也可明确选择停用对象或删除允许删除的文件凭证。一轮覆盖全部所选模型与每个样本位置，每个位置有完整、明确判定，且存在答错时，才应用答错处置。当前普通处置不沿用历史独立暂停的连续三轮阈值。缺项、未知、拒答、截断、取消、网络错误不构成完整答错证据。

上游错误是另一条策略。可以“答错仅检测，上游错误停用”，也可用没有标准答案的自定义、视觉及人工评审题，在支持的探测通道上处理明确错误。错误不累计答错；人工补充评审不自动处置。具体证据和目录缺项规则见 [上游错误处理](QUALITY_UPSTREAM_ERRORS_CN.md)。

自动恢复只在答错动作选择 `disable_credential` 时提供，默认关闭。规则定时也默认关闭；恢复沿用本规则 Cron 或立即执行。UI 新建规则的四项错误处置仍默认停用，旧明确配置保留。普通手动智商测试不执行规则的停用、删除或恢复策略。

## 范围与写入资格

| 对象 | 普通检测与恢复 |
| --- | --- |
| 当前启用 | 按类型、范围和能力纳入，使用本轮新证据应用策略 |
| 管理员停用、没有其他普通归属 | 全部范围可以保持停用检测；明确开启答错停用和自动恢复时，完整通过才可恢复 |
| 本规则答错停用 | 全部范围在恢复关闭时仍可检测；开启恢复时进入恢复分支，仅已启用范围也提供该例外 |
| 其他规则答错停用 | 全部范围可以检测和记录，不接管恢复或删除权限 |
| 上游错误停用来源仍有效 | 所有范围、所有规则均退出答题与恢复，直到观察到 CPA 启用 |
| 历史独立暂停、未知写入或身份冲突 | 继续保留各自保护 |

供应商单路由或整组由 CPA 实际能力决定。只能整组启停时，必须在规则中明确授权该组；检测类型、范围、单路由选择均不授予整组写入。答错处置要求整组完整可判定，恢复要求全部路由、模型和样本都正确。供应商配置删除不支持。

## 官方接口与实际探测

CPA 源码保持不变。插件业务入口为已认证的 `/v0/management/plugins/model-quality/`；SDK `/v8` 为 Go 模块版本。静态资源 GET 不执行业务操作。

| 接口或通道 | 用途 |
| --- | --- |
| `PATCH /v8/management/credentials/status` | 按已核实文件名与 auth_index 停用或启用文件凭证 |
| `DELETE /v8/management/credentials?name=...` | 删除一个已确认且允许删除的文件凭证，不使用 all/批量删除 |
| `POST /v8/management/requests/api-call` | 固定文件凭证、由 CPA 替换 `$TOKEN$`，支持停用期间探测 |
| 公共 SDK auth/model 回调 | 读取身份、运行状态和模型目录；手动与支持的普通观察使用 CPA 原生执行 |
| 官方认证供应商配置接口与定向 HTTP | 核实路由、读取当前密钥及映射，在后端内存定向探测；使用配置 ETag 条件启停 |

文件管理探测覆盖可精确核实的 OpenAI/Codex 等已有适配路径，不宣称所有运行时、虚拟或远端来源都支持。Codex 使用 Responses，OpenAI 使用 Chat Completions。供应商按具体协议构造请求；不支持的协议、思考参数、模型映射或请求头显示具体能力限制，不伪装成答错或上游错误。

管理探测不等于 CPA 业务执行器的全部模型映射、thinking 归一化、payload rules 或可信最终载荷证明。官方独立对照身份与 LLM judge 能力仍有限制；放开错误策略不解锁这些能力。CPA API-call 本身约 60 秒超时，插件管理客户端上限 70 秒；超时只记执行未知。该通道不自行实现 OAuth 刷新。

供应商密钥只在后端内存中用于当前请求，不进入前端、日志或答题历史。所有停用对象检测均保持停用，不临时启用。

## 条目归属与本轮快照

`CredentialDisposition` 将答错恢复归属 `answer_owner_rule_id` 与错误来源 `error_source` 分开。来源保存触发规则/版本、运行、路由、模型、错误、证据及时间；没有答错归属的首次错误停用不产生恢复权限。A 的答错归属被 B 的新上游错误覆盖检测资格时，A 仍是原归属者，B 只作为错误来源，不重复向 CPA 写停用。

长期条目关联通过 `sameCredentialEntry` 核对 AuthID、auth_index、文件名/组名、提供方与管理机制等定位字段，不比较 token、完整内容指纹或时间戳。可核实为同条目时，跨轮 token 刷新、账号内容替换或配置更新保留原答错归属。新一轮获取当前 `ManagedProbe` 快照；`sameSnapshot` 在执行与写前核对本轮内容、状态、时间或组成员。本轮改变使旧证据失效，不使长期归属因内容更新自动消失。

原处置授权的完整模型集合仍须核实，不能缩减恢复计划。两轮之间启用又停用且插件未观察到中间启用时，不用时间戳猜测历史；同条目答错标记保留。正常读取已观察到启用则结束旧恢复归属，之后新的人工停用按当前范围处理。

**条目定位不是永久身份承诺。** CPA 文件索引通常跟随类型与文件路径，供应商 AuthID/auth_index 可由密钥、URL、代理、前缀等配置派生。供应商换密钥改变标识后，公开接口没有可靠编辑事件或持久条目 ID，可唯一证明“原条目更新”而非“删除后新建”。插件不按名称、列表位置或完整配置摘要猜测继承恢复权；保留旧记录，当前已启用的新定位按当前身份正常使用。

已核实完整目录实际观察到旧定位消失时，将已确认记录转为 `entry_missing`，保留原记录和审计、取消旧任务，不再给同名重建对象旧恢复例外。目录失败或未核实的供应商目录不能证明删除。若删除与重建完全发生在两次读取之间且所有公开定位相同，现有 API 不能还原该历史；没有实现可保证所有供应商密钥替换连续性的持久映射。详见 [身份边界](QUALITY_OPERATIONS_ARCHITECTURE_CN.md#95-条目连续性的实现与公开接口限制)。

## 人工启用、生命周期与历史

管理员在 CPA 启用由 CPA 生效，主项目使用不等插件确认。插件在目录刷新、手动提交、派发及执行复查中读取当前状态，结束已确认的普通停用来源与旧恢复归属，保留历史和审计、取消旧任务并清除旧计数。合法供应商 `registered` 与 `active` 一致处理。读取失败显示实际连接或身份问题，不依据历史记录声称当前仍停用。

普通对象停用、恢复、外部启用和结果核对均不永久改写其他规则的启用或定时设置。被影响的当前任务可取消，其他对象继续。管理员停止的规则保持停止；来源不明的历史停止也不会批量启动。

操作意图先持久化，随后调用 CPA，再确认结果。未知回执进入待核对；重试、定时与重启均不重放。普通已确认停用不需要人工核对步骤。未确认记录保留“核对人工处理”：重新读取当前状态，确认外部已启用或移除后才结束关联，不写 CPA、不停止规则。

新规则每对象默认保留 100 条结果，范围 1–200 且至少容纳完整一轮；旧按天配置可保留。清空规则运行记录作用于全部规则，包括筛选外记录；不改变 CPA 状态、规则定时或手动测试历史。已确认错误证据可以从普通列表归档，来源仍持久保留。未知写入及所需完整证据继续受保护。

删除规则撤销该规则调度并清理可清理历史，不写 CPA 启停、不重建被删除凭证。仍有效的错误来源、触发证据和未知写入继续保留，不能靠删除原规则或错误触发规则绕过退出检测。进行中任务、进行中写入与历史独立质量暂停仍有删除限制。没有错误来源的已确认普通答错归属按原删除语义结束，不隐式启用对象。

已删除规则留下的未知处置在质量运维中单独列出，不依赖当前规则选择、分页或筛选。通过该记录的“核对人工处理”可核实 CPA 当前已启用或已移除，并结束本地隔离；仍停用、身份不明或供应商组成员未核实完整时不能解除。核对精确绑定 `auth_id` 与 `action_id`，不复建规则、不授予恢复权限、不发送 CPA 变更。现存规则的记录仍从其原入口核对。

## 写入并发与管理连接

文件状态/删除 API 没有对插件开放的原子条件写入、条件删除或独立 owner。写前核对与写后确认可拦截已观察到的修改，但最后检查与真正写入之间仍有外部并发窗口。供应商配置使用强 ETag/If-Match；条件冲突结束本次写入，不能盲目重试。历史 `pause_credential`、ActionID 和 BlockedAuthID 保留，不自动认领或解除。

后台管理授权经正式 CPA 鉴权后存入插件专用私有目录。恢复凭据、只读就绪检查与清除操作见[持久化说明](PERSISTENCE_CN.md)。管理探测或处置要求当前管理授权已就绪。页面退出对既有后台许可没有影响。

默认 CPA 管理地址 `http://127.0.0.1:8317`；其他监听端口由 CPA 进程环境 `MODEL_QUALITY_CPA_URL` 指定，限回环 IP，禁止代理与重定向。容器内使用容器监听端口。
