# 0.30.2 三轮持续审查

日期：2026-11-21（Asia/Shanghai）。本轮接续已经交付的 0.30.1，保留工作区全部已有修改。交付版本为插件 0.30.2、UI 13.7.2、内嵌 Go/Sobek 2.2.1；官方 CPA 8.0.76 源码保持不变。

## 审查与修复

第一轮检查前后端异常流程、授权状态和协议证据，先用失败测试复现。第二轮检查反向条件、旧记录、取消、重启和有效响应兼容性。第三轮独立交叉复核，再验证完整原生包、实际页面资源和本地数据保全。

| 实际问题 | 修复后的行为 | 主要位置 |
| --- | --- | --- |
| 全局关闭或规则暂停时，关闭单条规则定时只返回成功，未撤销原授权 | 按持久授权判断是否需要关闭；后续全局重开、恢复规则或重启均不能重新调度该规则，其他规则及立即执行保持独立 | `plugin/quality/rules.go`、`commercial_permissions_test.go` |
| 删除规则后未知写入仍被隔离，却失去人工核对入口 | 现有规则查询返回安全的孤立处置摘要，页面显示独立核对入口；精确匹配对象与动作，再核实当前启用或移除。仍停用、身份不明、组成员不完整时拒绝；不重放写入或恢复规则 | `credential_policy.go`、`provider_disposition.go`、`queries.go`、前端运维页面 |
| Responses 同时声称完成并携带截断原因，仍触发停用、删除或恢复 | 非空 `incomplete_details` 使答案证据无效；六个实际假 CPA 写入反例与拼接响应一起修复为零写入、未知判定 | `management_client.go`、`commercial_protocol_test.go` |
| 不同响应 ID 的流片段被拼成同一份答案 | Chat 与 Responses 在出现 ID 后检查一致性；Responses 同时核对事件引用及响应模型，保留字段省略的旧协议兼容 | `collector.go`、`management_client.go` |
| 旧式函数调用或非预期 choice 被当作普通答案 | 拒绝非空 `function_call` 及非零/非法 choice 索引，避免工具输出成为质量证据 | `collector.go` |
| 正常 Chat 响应携带 `tool_calls: null` 被误拒绝 | 将明确为 null 的未使用工具字段按缺省处理，正常回答可完整判定 | `collector.go` |
| 同组多个成员共享动作 ID，点击第二个成员却提交第一个 | 列表键和核对按钮均使用动作 ID 与对象 ID 的组合身份，准确核对用户所选记录 | `plugin/ui/app.js`、`view.js` |
| 断连或鉴权失效后，旧异步反馈覆盖当前连接状态 | 定时失败补读、未知运行回执补读、核对后补读均检查当前连接会话，失效响应不再显示旧成功或错误提示 | `plugin/ui/app.js` |

原有两条处置策略、当前 CPA 状态同步、跨规则答错恢复归属、历史独立暂停和未知写入保护保持。所有验证使用假凭证、临时数据库、合成页面或网络隔离容器，不执行真实账户操作。
